## 🔧 Projects

### [UART Serial Transceiver](https://github.com/lucastinter07/uart-transceiver) · *VHDL*
A full-duplex UART transmitter/receiver written from scratch in VHDL. Verified in simulation with GHDL and GTKWave, with architecture diagrams and full documentation. Next step is hardware bring-up on an Altera DE2 FPGA board.

### [ESP32-S3 Market Tracker](https://github.com/lucastinter07/esp32markettracker) · *ESP32* · 🚧 in progress
A desk-sized stock ticker built on an ESP32 with an LCD that shows prices for a chosen watchlist. A possible next stage is designing a PCB to replace the devkit.

### Up Next: Custom FPV Drone w/ Computer Vision
A drone built from scratch: a self-designed flight controller PCB, hand-written control loops, a custom airframe, and auto-tracking.
